焦點新聞 · 選文與分類

每天上百則新聞，怎麼決定哪些收、放哪一段

這頁把整套判斷規則攤開講清楚。每一則候選都走同一套流程，答案決定去留與分段——關鍵字會隨時期換，底層的判斷視角不變。

整套規則是依長期剪報樣本逐條歸納出來的。做法是：先問四個問題決定去留與分段（§2），跨段模糊的再查裁決表（§6），最後用重要度訊號排序（§8）。

01三段對應三個問題

為什麼是這三段？因為讀者每天早上要回答三件事：

永豐相關

外界今天怎麼說我們？

自家的聲譽與曝險——有沒有需要處理的負面消息。

金融產業

同業與法規有什麼變化？

競爭者做了什麼、主管機關要求什麼、商品市場變了什麼。

總經相關

資金與風險往哪走？

錢往哪裡流、風險從哪裡來的整體環境。

另外有四條貫穿全部的「引力法則」——實際上最容易入選的稿都符合其中之一：

  • 監理優先：金管會、央行、財政部一有動作，幾乎必收。
  • 紀錄敏感：標題含「新高／新低／連 N 紅／首度／破 X 兆」是最強的單一入選訊號。
  • 議題全程追蹤：一項政策從醞釀 → 草案 → 定案 → 上路，全程跟到落地。
  • 危機連續劇：系統性風險事件每天跟進，直到收斂。
段別目標則數上限
永豐相關0–5（可為 0，無稿整段留白）8
金融產業5–813
總經相關8–1216

全篇日均約 18 則，寧缺勿濫。唯一例外：永豐的負面事件必收、置頂，不受目標數限制。

02四問分流：逐則依序問，命中即停

  1. 涉及永豐體系嗎？　是 → 永豐段（正負面都收；負面必收、置頂）
  2. 命中排除清單嗎？（見 §7）　是 → 丟棄
  3. 主角是金融機構／監理機關／金融商品嗎？　是 → 金融產業段
  4. 影響資金與市場的總經或國際事件嗎？　是 → 總經段
  5. 以上都不是　→ 丟棄（寧缺勿濫）

注意順序：第 1 問排在第 2 問之前。所以涉及永豐的社會案件照收（一般社會案件本來屬於排除類）——永豐永遠優先判斷。

03什麼算「永豐是主角」

關鍵是永豐為新聞的主角，不是被順帶提到、被引用一句話、或只是名單裡的一員。以下都算：

  • 法人：永豐金控／銀行／證券／投信／租賃，以及併購對象京城銀。
  • 人：高層或首席具名發言——即使談的是總經，也歸永豐段。
  • 商品：自家 ETF、信用卡、數位帳戶等。
  • 贊助資產：永豐雲豹（籃球）、冠名活動——只收里程碑（封王、晉級、奪冠），例行賽果不收。
  • 負面事件：詐貸、違約、裁罰、客訴——必收、置頂，不受目標數限制。

執行細節——看網址不看主題：跳過的是永豐自家平台的行銷／教學頁；但同一件事若有外部媒體報導版，就收外部版（不要一看到自家品牌名就整題斃掉）。同一則新聞稿多家轉載，只留 1–2 家（優先主流媒體）。

06跨段裁決：同一件事，角度不同會分到不同段

十個常年跨界的主題，以「角度」定段。同一事件因角度不同而分到不同段，這不是錯誤，是規則。

主題機構／承作角度 → 金融產業市場／行情角度 → 總經
房市房貸利率／成數、央行信用管制決策本身價量、推案、建商；管制對房市的影響評估

表外的案例回到三條原則：

  • 主題優先於發言者——唯一例外是發言者屬永豐（覆寫到永豐段）。
  • 機構／商品 vs 市場——監理動作對「機構或商品」歸金融產業；對「整體市場」歸總經。
  • 承作端 vs 行情端——金融機構做的事歸金融產業；價格與供需的結果歸總經。

07一定排除的

基本五類

體育娛樂追星／社會案件犯罪意外／與金融無關的個股／生活健康旅遊／純政治口水。

補充四類

廣編業配（無事件、通篇形容詞）／選股清單（「14 檔外資連買」）／贊助隊伍例行賽果／與永豐無關的獎項活動。

反向豁免（避免誤殺）

個別企業的聯貸／違約算金融產業（銀行視角）；涉財經政策的政治新聞算總經；涉永豐的社會案件歸永豐段。

08重要度訊號

  • 兩大報同一天報同一件事＝最強訊號，必收並置頂。選文開始前會先掃一遍候選池找這種同題。
  • 標題數字化：含具體數字／紀錄詞的優先，純形容詞的降級。
  • 週期議題日曆：可預期的議題有時間表——月初 PMI、月中 CPI 與金控月報潮、季底央行理監事會等——選文時主動核對有沒有漏抓。
